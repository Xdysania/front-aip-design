Overview 总览

AIP · Libra · 顶栏（唯一视觉）

令牌见 aip-design-system.css（对齐典型页 Libra shell）。基本元素 / 基础组件 / 业务组件演示一律嵌入典型页真实 DOM（?embed=basics|topbar|…），禁止 Kit 自造简化稿。

怎么用

  1. 读左侧面板活体 demo，不要整文件硬读 HTML。
  2. 出页先读 docs/spec-usage.md 与 docs/templates/list-page.md。
  3. 样式只用 var(--aip-*)；业务壳组合 Topbar / ContractSidebar / TaskList。

Modal 对话框

自典型页抽取 · .ns-modal-mask + .ns-modal

蒙层必须使用 --aip-mask-bg + --aip-mask-blur（backdrop-filter: blur()），业务页 .ns-modal-mask 同源；禁止仅半透明无模糊。 禁止自造确认框。典型页实例：设置列表列、新建文件夹（同源嵌入，改典型页即改此处）。 直链：迭代稿协议页
